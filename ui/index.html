איך משתמשים?

      
1. הכנס API key בהגדרות (⚙️)

      
2. כתוב מה אתה רוצה לבנות

      
3. לחץ "בנה" או Enter

      
4. קבל תוכנית + קוד + תצוגה

      
5. לחץ "שפר" כדי לשפר את הקוד

      

      
קיצורי מקלדת:

      
Enter - בנה

      
Shift+Enter - שורה חדשה

      
Ctrl+Enter - בנה (חלופי)

      

      
טיפים:

      
• השתמש בתבניות להתחלה מהירה

      
• לחץ "תצוגה" כדי לראות את הקוד בפעולה

      
• לחץ "שתף" כדי לשלוח קישור עם המשימה

      
• בדוק את ההיסטוריה כדי לטעון משימות קודמות
